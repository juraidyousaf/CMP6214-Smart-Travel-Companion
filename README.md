| Label | Meaning |

| VERIFIED | You opened the source and recorded it in `research/source-register.md` |
| HYPOTHESIS | A problem, feature, or design idea without research support yet |
| ILLUSTRATIVE | A teaching example. Not project evidence and not for submission as a finding |
| INCOMPLETE | A template waiting for your writing |
