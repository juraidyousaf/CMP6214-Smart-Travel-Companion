## Approved draft

Google Maps provides walking directions using the device's GPS, location services and speakers to guide users towards their destinations (Google, no date-b). Its Android accessibility documentation describes detailed voice guidance that announces the distance to the next turn while walking (Google, no date-a). The iOS navigation documentation also explains that spoken directions can continue when the phone screen is switched off (Google, no date-b). However, the official pages reviewed for this comparison do not describe a dedicated sightseeing guide or establish the full capabilities of multi-stop sightseeing planning. These findings are based on official product documentation rather than hands-on testing of the application.

Google Maps provides several accessibility features on Android, including TalkBack screen-reader support and text sizing that follows the phone's accessibility settings (Google, no date-a). The documentation also describes one-handed zoom and pan controls, along with a wheelchair-accessible filter for public transport routes. Accessibility information for places may include entrances, restrooms, seating, parking and elevators, although these details are available only in certain countries. However, Lens in Maps with TalkBack is not supported on tablet-sized devices (Google, no date-a).

Wanderlog provides itinerary-planning features that allow users to view travel times and distances between places using walking, driving or public transport (Wanderlog, 2023a). Its Pro version includes a route optimisation feature that can rearrange destinations within a single day to reduce travel time and fuel consumption (Wanderlog, 2023b). Additionally, Pro users can download their trip plans, including notes, saved places and attachments, for offline access (Wanderlog, 2023c). However, offline access refers to the saved trip plan rather than live navigation. These findings are based on Wanderlog's official documentation and do not establish whether the application provides turn-by-turn walking guidance or smart-glasses functionality.

Tripadvisor provides a Trips feature that allows users to save and organise places to stay, attractions and restaurants in one place (Tripadvisor, no date). According to its official support page, users can create a Trip through the Trips icon or save a hotel, attraction or restaurant using the heart icon. Users can also edit trip names and descriptions, organise saved items, manage privacy settings and add collaborators. However, the reviewed documentation does not explain how users initially find these places or provide details about walking navigation, accessibility, pricing or smart-glasses features.

This competitor analysis is based entirely on official product documentation, as no applications were tested directly and no screenshots or user reviews were collected. The Google Maps documentation about adding multiple destinations was not examined, while the reviewed Wanderlog pages did not provide accessibility information. Tripadvisor's accessibility statement could not be accessed, so its accessibility features remain unverified. A possible design hypothesis for Smart Travel Companion is to investigate whether city tourists would benefit from connecting attraction discovery, walking-route planning and accessibility information within one experience, although this idea has not yet been tested.
